# Warragul Multigenerational Transition & Cashflow Portfolio Modeler

An elegant, interactive, and high-fidelity modeling application designed to evaluate and map out complex multigenerational real estate transitions, cash flow timelines, and mortgage recasting strategies. 

This modeler handles parallel settlement lags, dynamic sale prices, capital contributions, and starting offset drawdowns—ultimately calculating critical financial metrics such as **Years to Offset Forever Home** and **Years to Complete Portfolio Freedom**, tracking lifetime interest exposure globally.

## 🏔️ Proxmox VE Installation Instructions

Proxmox Virtual Environment (PVE) is ideal for hosting this application. Below are three methods to deploy the application on your Proxmox server depending on your preferred home lab architecture: **LXC (Highly Recommended)**, **Docker / Portainer**, or as a **Production Nginx Website**.

### Method 1: Bare-Metal LXC Container (Debian/Ubuntu) — Recommended
LXC containers are extremely lightweight and provide high performance with minimal overhead.

1. **Create an LXC Container** in your Proxmox web interface:
   - **OS Template**: Select Ubuntu 22.04 / 24.04 or Debian 12.
   - **Compute**: 1 Core, 512MB - 1GB RAM, and 8GB Disk space is more than enough.
   - **Networking**: Assign a static IP (e.g., `192.168.1.150`) or use DHCP.

2. **Access the Container Console** (or SSH into it) and run the following system updates:
   ```bash
   apt update && apt upgrade -y
   apt install -y git curl sudo build-essential
   ```

3. **Install Node.js (v20+ LTS)**:
   ```bash
   curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
   sudo apt install -y nodejs
   ```

4. **Clone & Set Up the Repository**:
   ```bash
   git clone <YOUR-REPOSITORY-URL-OR-COPY-FILES> /opt/warragul-modeler
   cd /opt/warragul-modeler
   npm install
   ```

5. **Configure PM2 Process Manager** (ensures the app runs persistently in the background and restarts on container boot):
   ```bash
   sudo npm install -y pm2 -g
   pm2 start npm --name "warragul-modeler" -- run dev
   pm2 save
   pm2 startup
   ```
   *(Copy and paste the command generated by `pm2 startup` to configure the systemd service hook.)*

### Method 2: Docker Compose inside VM or LXC (Portainer Friendly)
If you run a Docker VM or a nested Docker LXC inside Proxmox:

1. Create a `docker-compose.yml` file in the project folder:
   ```yaml
   version: '3.8'

   services:
     warragul-modeler:
       image: node:20-alpine
       container_name: warragul-modeler
       working_dir: /app
       volumes:
         - .:/app
       ports:
         - "3000:3000"
       command: sh -c "npm install && npm run dev"
       restart: unless-stopped
   ```

2. Run the stack:
   ```bash
   docker compose up -d
   ```

---

### Method 3: Hosting Built Static Files with Nginx (Ultra-Lightweight Production Setup)
Since this is a Client-Side Single Page Application (SPA), hosting the compiled static files using a native Nginx server consumes virtually 0% CPU and less than 15MB of RAM inside an LXC.

1. **Step 1: Build the static assets** on your workstation or temporary container:
   ```bash
   npm install
   npm run build
   ```
   This generates a self-contained static folder under `/dist`.

2. **Step 2: Install Nginx** in your Proxmox LXC:
   ```bash
   sudo apt install -y nginx
   ```

3. **Step 3: Transfer files**: Copy the contents of the local `/dist` folder to the container's web server path:
   ```bash
   # Inside the LXC, files should live here:
   /var/www/html/
   ```

4. **Step 4: Configure Nginx to support SPA Router** (Optional placeholder for page refreshes):
   Create a site configuration file `/etc/nginx/sites-available/default`:
   ```nginx
   server {
       listen 3000 default_server;
       listen [::]:3000 default_server;

       root /var/www/html;
       index index.html index.htm;

       server_name _;

       location / {
           try_files $uri $uri/ /index.html;
       }
   }
   ```
5. Restart Nginx:
   ```bash
   sudo systemctl restart nginx
   ```

## 🛠️ Dynamic Core Features & Simulation Flow

Warragul Multigenerational Modeler handles complex interconnected components seamlessly:

### 📊 1. GANTT Timeline Schedule Planner
- **Interactive Timetables**: Visualizes overlapping project swimlanes spanning home renovations, active real estate marketing campaigns, logistical relocation windows, and multiple dynamic property settlement lags.
- **Visual Schedule Overlay Warning**: Flags scheduling conflicts automatically (e.g., if Forever Home settlement precedes Meryl's Twin Ranges Sale completion, highlighting the transition lag.

### 🎚️ 2. Dynamic Real Estate & Sale Sliders
- **Paulan Court Sale Breakdowns**: Equipped with a contract price range slider ($500k to $1.2M), immediately updating selling agent commission at a 2.5% fixed fee, settling the outstanding $381,446 mortgage debt, and routing the exact **Net Cash Settle Released** to the post-sale investment pool.
- **Twin Ranges Sale Price & Capital Contribution**: Slide Meryl's Twin Ranges Gross Sale Price from $500k to $1.2M. The model dynamically deducts 2.5% in fees, limits the legal retirement/granny flat capital contribution slider, and displays her cash surplus automatically.

### 💰 3. Internal Variation & Recasting Allocation
- **Fine-Grain Granularity**: A high-precision allocation slider with 2.5% increments lets you decide how much of the joint post-sale cash portfolio goes directly toward **recasting the principal loan** ($0 to 100%) vs. keeping funds liquid in the offset pool.

### 📉 4. Dynamic Interest & Milestone Solvency Models
- **Years to Offset Forever Home**: Computes the exact time required to fully isolate and neutralize interest on the primary mortgage. Tracks the precise **cumulative interest paid** until neutralization is achieved based on weekly savings additions.
- **Years to Complete Portfolio Freedom**: Computes portfolio freedom timelines with complete granular breakdowns:
  1. Cumulative interest paid on the **Fern Street Holiday House Loan**.
  2. **Combined Total** loan interest paid across all property assets.

## 📥 Local Snapshots & Self-Contained HTML Exports

A crowning utility of the system is the **Standalone Report Snapshot Engine**:
1. Select your preferred parameters, timelines, and recast configurations.
2. Click the **Export HTML Report** button located under the "Scenarios Dashboard".
3. This downloads a self-contained, fully responsive offline-accessible HTML report. It can be printed as a PDF, archived, or shared with mortgage brokers or financial advisors directly.
